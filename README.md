# hxyfront-62011 马术蹄温预警与训练禁入

源提示词编号：6（由「马术蹄铁修整档案」升级）

面向马术俱乐部的蹄温晨检与训练禁入闭环：

- **唯一有效蹄温**：每匹马每个蹄位每天只保留一条有效蹄温；同键再次提交视为更正，旧记录留档可查。
- **蹄叶炎预警**：左右前蹄温差 > 1.5℃ 或任意单蹄 > 38.5℃ 即进入蹄叶炎观察，并禁止列入当日训练名单。
- **观察闭环**：观察期必须记录降温处置，且连续两次复测正常才允许解除；解除后若原蹄温被更正，旧解除立即失效（留档），观察重新开启。
- **幂等提交**：每次录入携带提交凭证，重复或并发提交一律沿用首次结果。
- **状态一致**：马匹列表、当日蹄温总览、观察名单与训练名单均由同一份持久化状态（localStorage）派生，刷新后保持一致。

## 分层结构

```
src/
  domain/hoofDomain.ts   业务判断：阈值、预警判定、观察解除资格、训练禁入（纯函数）
  domain/roster.ts       马匹档案（修蹄档案名册）
  storage/hoofStore.ts   记录存储：localStorage 持久化、幂等提交、更正失效、并发合并
  ui/                    页面展示：录入表单、当日总览、观察闭环、训练名单、留档
  App.tsx                组合入口
```
